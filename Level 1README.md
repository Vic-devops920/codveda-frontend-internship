# Hope Foundation Charity Website (Level 1)

## Overview

This project was developed as part of my Front-End Development Internship at Codveda Technologies.

The aim was to complete two Level 1 tasks:

1. Responsive Landing Page
2. Interactive Form

Instead of creating separate projects, both tasks were combined into a single volunteering charity website called Hope Foundation.

## Features

### Responsive Landing Page
- Semantic HTML5 structure
- Mobile-first responsive design
- CSS Grid and Flexbox layouts
- Smooth scrolling navigation
- Basic animations and transitions
- Hero section, mission section, impact statistics, and contact section

### Interactive Form
- Volunteer registration form
- Real-time validation
- Dynamic error messages
- Password strength indicator
- Focus and blur event handling
- Successful submission feedback without page reload

### Additional Features
- Vacancies section
- Role and region filtering
- One-click Apply functionality
- Responsive design across desktop, tablet, and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Learning Outcomes

Through this project, I gained practical experience in:
- Responsive Web Design
- Semantic HTML
- CSS Grid and Flexbox
- DOM Manipulation
- Form Validation
- Accessibility Best Practices
- User Experience Design
